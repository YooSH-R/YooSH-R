# 유성현

의료기기 회사의 홈페이지를 리뉴얼하며 프론트엔드 개발을 시작했습니다. 이후 팀 프로젝트에서 백엔드 API와 데이터베이스를 설계했고, 최근에는 영어 회화 서비스 Elsehere의 인프라를 맡아 GitLab CI/CD 파이프라인을 구축했습니다.

## KDT | 프론트엔드 개발 과정

| 프로젝트 | 직접 맡은 일 |
| --- | --- |
| 유정메디텍 리뉴얼 | 첫 개인 프로젝트. 회사 소개와 취급 제품을 한 페이지에 구성하고 브랜드별, 분야별 제품 탐색 구현 |
| YES24 리뉴얼 | 3인 팀에서 사용자 흐름과 DB 설계. 상품 상세, 장바구니, 관리자 페이지 전체 개발 |

## 삼성청년SW·AI아카데미(SSAFY)

| 프로젝트 | 직접 맡은 일 |
| --- | --- |
| WhatSub | 2인 팀의 프론트엔드 담당. OTT 구독 관리 화면, 요금제 비교 계산기, 커뮤니티 게시글과 댓글 기능 개발 |
| 마실 | 반려 로봇 서비스의 백엔드 담당. 소셜 로그인, 펫과 로봇 연결, 산책 기록 API 개발 |
| thispatch | 게임 공지의 패치 판정 로직, 리뷰 집계와 분석 API 개발 |
| Elsehere | 영어 회화 서비스의 인프라 담당. GitLab CI/CD 파이프라인 구축, 배포 자동화와 DB 백업 복원 검증 |
